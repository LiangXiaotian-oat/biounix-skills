# 内容嗅探表（Content Sniffing）

对纯文本格式（无魔数），读取文件**前 2KB**，按首行/首字符模式判定。仅当魔数无命中且扩展名不明确时启用。

## 生物信息文本格式

| type        | 首行/首字符模式                                                                             | 典型扩展名     | 备注                                                 |
| ----------- | ------------------------------------------------------------------------------------------- | -------------- | ---------------------------------------------------- |
| `fasta`     | 首字符 `>`                                                                                  | `.fa`/`.fasta` | 标题行后跟序列行                                     |
| `fastq`     | 首字符 `@`，第 1/3 行 `@`/`+`，第 4 行为质量值（ASCII 33–126）                              | `.fq`/`.fastq` | 需验证 4 行一组结构，避免与 SAM（也以 `@` 开头）混淆 |
| `sam`       | 首行 `@HD`/`@SQ`/`@RG`/`@PG`/`@CO`（header），或首行 tab 分隔且第 1/3 字段为 read name/flag | `.sam`         | header 可选；无 header 时看第 6 列是否为 CIGAR       |
| `vcf`       | 首行 `##fileformat=VCF`                                                                     | `.vcf`         |                                                      |
| `bcf`       | 非文本（BGZF），见魔数表                                                                    | `.bcf`         |                                                      |
| `bed`       | 首行 `track`/`browser`，或首行 ≥3 列 tab 分隔且第 1/2/3 为 chrom/start/end（数字）          | `.bed`         | start/end 必须为整数                                 |
| `gff`/`gtf` | 首行 `##gff-version`，或行有 9 列 tab 分隔且第 7/8 列为 strand/phase                        | `.gff`/`.gtf`  |                                                      |
| `maf`       | 首行以 `#` 注释，随后为 tab 分隔列，含 `Hugo_Symbol`/`Tumor_Sample_Barcode` 等              | `.maf`         |                                                      |

**fasta vs fastq 区别**：FASTA 首字符 `>`，无质量值；FASTQ 首字符 `@`，4 行一组。**SAM header 也以 `@` 开头**，区分方法：SAM header 行是 `@HD`/`@SQ` 等 2 字符标签，FASTQ 的 `@` 后直接是 read name。

## 通用文本格式

| type       | 首行/首字符模式                        | 典型扩展名     | 备注                      |
| ---------- | -------------------------------------- | -------------- | ------------------------- |
| `json`     | 首字符 `{` 或 `[`，可解析为 JSON       | `.json`        |                           |
| `jsonl`    | 每行独立 JSON 对象/数组                | `.jsonl`       | 多行且每行以 `{`/`[` 开头 |
| `xml`      | 首字符 `<`，含 `<?xml` 声明或 `<root>` | `.xml`         |                           |
| `yaml`     | 首行 `---` 或 `key: value` 形式        | `.yaml`/`.yml` |                           |
| `csv`      | 首行含逗号分隔字段，无固定魔数         | `.csv`         |                           |
| `tsv`      | 首行含 tab 分隔字段                    | `.tsv`/`.tab`  |                           |
| `markdown` | 首行 `#` 标题或含 `*`/`-` 列表         | `.md`          |                           |
| `html`     | 首字符 `<`，含 `<!DOCTYPE` 或 `<html`  | `.html`        |                           |
| `ini`      | 首行 `[section]` 或 `key=value`        | `.ini`/`.cfg`  |                           |

## 嗅探策略

1. **先看首字符**：`>`/`@`/`#`/`<`/`{`/`[` 可快速分流。
2. **再看首行结构**：tab 分隔列数 + 列内容类型（数字/字符串）。
3. **多行验证**：对 FASTQ 验证 4 行一组；对 SAM 验证 CIGAR；对 BED 验证坐标为整数。
4. **歧义回退**：若首行同时匹配多个模式（如 `@` 可能是 FASTQ 或 SAM），读取更多行验证结构。

## gzip 容器内容嗅探

对 `.gz` 文件（魔数 `1f 8b 08`）：

1. **不要**仅凭后缀判定内部格式。
2. 用 `gzip -dc file | head -c 2048`（或 Python `gzip.open`）解压前 2KB 嗅探。
3. 解压后内容按上表判定（如解压后首行 `##fileformat=VCF` → `vcf.gz`）。
4. 若解压后仍是二进制（如 BAM），回到魔数表判定（BAM 解压后首四字节 `BAM\1`）。
