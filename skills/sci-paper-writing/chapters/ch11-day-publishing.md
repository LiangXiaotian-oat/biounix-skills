# Chapter 11: Day - How to Write and Publish a Scientific Paper

## Core Idea
Robert A. Day classic guide on the mechanics of scientific publishing: from designing tables and figures, to submitting, surviving peer review, and presenting at conferences.

## Effective Tables
- A table should supplement, not duplicate, text
- If data can be stated in one sentence, do not use a table
- Be suspicious of tables with many zeros or 100s
- Watch for +/- sign tables that could be expressed in words
- Give only significant figures; omit unessential data

## Effective Figures and Photographs
- Photographs value ranges from zero to transcending the text
- For cell ultrastructure studies, photos may be the main point
- Choose journals with high-quality reproduction (150-200 line screens, coated stock)

## Editor Decision Types
- **Accept**: Rare (~5% in good biology journals)
- **Reject**: Common. Consider feedback, revise, submit elsewhere
- **Modify**: Most common. Address each reviewer comment point by point
- Decision usually in 4-6 weeks; contact editor if no response in 8 weeks
- Editors are allies, not adversaries

## Revision Process
- Provide point-by-point response to each comment
- Never argue without evidence; explain disagreement with data or citations
- Mark changes in revised manuscript for easy review

## Conference Presentations
### Slides
- Use sans serif typeface (e.g. Helvetica)
- Black text on white background for best contrast
- Each slide: one simple visual statement
- If a slide cannot be understood in 4 seconds, it is a bad slide
- Never read slide text to the audience
- Check projector and slide order before presentation

### Oral Presentation
- Pitch at more general level than written paper
- Avoid technical detail; define terms; explain difficult concepts
- A bit of redundancy can be helpful
- Audience is more diverse than journal readership

## Abbreviations
- Never use abbreviation in title
- Rarely use in abstract (define at first use if needed)
- In text: spell out first, then abbreviate in parentheses
- Accepted abbreviations change over time (e.g. DPN -> NAD)
- Good practice: spell out all terms in first draft, then abbreviate

## Words and Expressions to Avoid
| Avoid | Use Instead |
|-------|-------------|
| the question as to whether | whether |
| the reason is because | because |
| the vast majority of | most |
| there is reason to believe | I think |
| this result would seem to indicate | this result indicates |
| through the use of | by, with |
| utilization / utilize | use |
| very unique | unique |
| was of the opinion that | believed |
| we have insufficient knowledge | we do not know |
| with reference to / with regard to | about |

## Key Takeaways
1. Tables: if data fits one sentence, do not use a table
2. Figures: choose journal with good reproduction quality
3. Editor decisions: accept rare, modify most common
4. Revisions: point-by-point response with evidence
5. Slides: one idea per slide, understandable in 4 seconds
6. Abbreviations: never in title, rarely in abstract
7. Watch for wordy expressions - use the concise alternative
