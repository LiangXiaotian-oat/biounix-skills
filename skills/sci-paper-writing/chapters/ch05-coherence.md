# Chapter 5: Coherence

## Core Idea
Coherence is achieved by managing topic strings across sentences and paragraphs. Readers feel coherence when each sentence opens with familiar information and introduces new themes near the stress position.

## Frameworks Introduced
- **Topic Strings and Thematic Strings**: Topic string = chain of subjects across sentences. Thematic string = recurring concept threading through a paragraph. Both must be consistent.
- **Signaling New Themes**: Introduce new themes as close to the end (stress position) as possible. This signals what to expect next.
- **Repeating Key Terms**: Deliberately repeat core terms - do not vary terminology if it breaks the chain.
- **Issue + Discussion Structure** (Williams): Paragraphs have an issue (short opening) and discussion (longer development). The end of the issue signals topics for the discussion.

## Key Concepts
- **Coherence I**: Managing how new strings start - signaling topics and themes.
- **Coherence II**: Managing how strings develop - maintaining consistency and points.
- **Point sentence**: The sentence in a paragraph that states the main claim.

## Mental Models
- Promise and deliver: the end of one sentence promises what the next discusses.
- Paragraphs as woven fabric: topic strings are warp, thematic strings are weft.
- Diagnostic test: list first and last words of each sentence to check coherence.

## Anti-patterns
- **Broken topic strings**: Suddenly switching topics without connection.
- **Premature theme introduction**: New themes at beginning rather than end.
- **Synonym substitution**: Replacing key terms with synonyms breaks the chain.

## Worked Example
"Clark's practice of carefully mapping every fossil made it possible to follow the evolutionary development of various types through time."

Analysis: The end signals topics for the rest of the paragraph: evolutionary development, various types, development, time. By placing these at the stress position, the author promises what comes next.

Contrast: "Clark made it possible to follow the evolutionary development of various types through time because he mapped every fossil carefully." - Here carefully is in stress position, which does not signal the next topic.

## Key Takeaways
1. Introduce new themes near the end of sentences
2. Maintain consistent topic strings across sentences
3. Repeat key terms deliberately - do not substitute synonyms
4. The end of each sentence should promise what the next delivers
5. Use the diagnostic test: list first/last words to check coherence
