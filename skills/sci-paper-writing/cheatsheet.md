# Quick Reference and Decision Guide

## Writing Diagnostic Checklist

| Problem | Check | Fix | Ch |
|---------|-------|-----|----|
| Sentence unclear | Subjects=characters? Verbs=actions? | Convert nominalizations to verbs | 2 |
| Paragraph not flowing | Old info at start, new at end? | Rearrange to old-to-new | 3 |
| Key point lost | Important info at end? | Trim/shift to stress position | 4 |
| Paragraph disjointed | Topic strings consistent? | Repeat key terms, fix chains | 5 |
| Writing wordy | Redundant/inflated phrases? | Delete redundancies, compress | 6 |
| Long sentences confuse | Sentence has shape? | Coordination/subordination, short subjects | 7 |
| Writing flat | Rhythm and balance? | Vary length, use parallelism | 8 |
| Unsure about rule | Real rule or folklore? | Split infinitives OK, prepositions OK | 9 |

## Active vs Passive Decision

| Question | If Yes | If No |
|----------|--------|-------|
| Must audience know who acts? | Active | Consider passive |
| Is subject string consistent? | Keep it | Revise subjects |
| Is it the right string? | Proceed | Change subjects |

## Writing Order

| Step | Section | Why |
|------|---------|------|
| 1 | Methods | Know it best |
| 2 | Results | Record as data comes |
| 3 | Introduction | After selecting journal |
| 4 | Discussion | After results fixed |
| 5 | Conclusion | After discussion |
| 6 | Title | Distill finalized paper |
| 7 | Abstract | Compress whole paper |

## Wordiness Quick Fix

| Wordy | Concise |
|-------|---------|
| each and every | each |
| future plans | plans |
| large in size | large |
| due to the fact that | because |
| in the event that | if |
| it should be noted that | (delete) |
| in my personal opinion | (delete) |
| utilization / utilize | use |
| very unique | unique |
| with reference to | about |

## Grammar: Real vs Folklore

| Rule | Status | Action |
|------|--------|--------|
| No split infinitives | Folklore | Split when clearer |
| No preposition at end | Folklore | End naturally |
| No start with and/but | Folklore | Use for emphasis |
| Subject-verb agreement | Real | Always follow |
| Data is plural | Real | Use data show |
| Irregardless | Real error | Use regardless |

## Abstract Structure

| Section | Content | Length |
|---------|---------|--------|
| Background | Context + purpose | 2-3 sentences |
| Results | Main findings | 3-5 sentences |
| Conclusions | Summary + implications | 1-2 sentences |
| Total | | Max 350 words |

## Title Checklist

- [ ] Specific terms
- [ ] Simple word order
- [ ] No abbreviations or acronyms
- [ ] Full scientific names
- [ ] No Roman numerals
- [ ] Common/generic chemical names

## Table Decision

| Situation | Action |
|-----------|--------|
| Data fits one sentence | No table - write it in text |
| Many zeros or 100s | Suspicious - simplify |
| Only +/- signs | Express in words |
| Statistical tests included | Check significance |

## Introduction Funnel Structure

| Element | Content | Example (rice blast) |
|---------|---------|---------------------|
| Context | Broad importance | Rice feeds half the world |
| Transition | Gap or need | Non-race-specific resistance more effective |
| Point | Your contribution | We identified a C2H2-type TF allele |
| Results | Key findings | 10% of rice has this allele |
| Significance | Broader impact | Strategy for breeding durable resistance |

## Reviewer Response Rules

| Situation | Response |
|-----------|----------|
| Reviewer correct | Acknowledge and fix |
| Reviewer incorrect | Explain with data/citations |
| Additional experiment needed | Do it or explain why not |
| Unclear comment | Ask for clarification politely |
